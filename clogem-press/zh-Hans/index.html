clogem-press 是什么

clogem-press 用一个存放 Markdown 文件的文件夹构建静态网站：知识库、博客、文档，或者三者合一的网站。它沿用 vuepress-theme-vdoing 的内容约定：带编号的文件夹成为侧边栏，front matter 会自动替你写好，每篇文章都有一个简短的永久地址。

它运行在 babashka（英文） 上，无需安装任何库：Markdown、模板、YAML、HTTP 和订阅源都已内置在 babashka 中。

一个网站最多可以包含五种语言：英语、简体中文、繁体中文、马来语和泰米尔语。同一篇文章的各语言版本共用一个地址，读者可以在它们之间切换。

最新版本是 0.2.0。下一阶段的工作正在 main 分支上进行，尚未发布。更新日志（英文）会随时列出每一项已合入的改动。

内容与结构

由带编号的文件夹生成侧边栏，自动写好 front matter 并提供稳定的永久链接，分类、标签和归档页面，可分页并支持置顶文章的博客首页，面包屑导航，上一篇和下一篇链接，目录页，以及 Markdown 容器。

已发布 · 0.2.0

多语言与内容发现

五种语言，每篇文章一个地址；canonical 和 hreflang 链接，每种语言一个 Atom 订阅源，站点地图，每种语言各有索引的 Pagefind 搜索，以及可选的 giscus 评论，每篇文章一个讨论串。

快速上手

你需要 babashka（英文） 1.13.219 或更新版本，以及 git。clogem-press 在你的网站文件夹中运行，使用放在它旁边的一份生成器副本：

git clone https://github.com/EchoJustus/clogem-press
cd my-site
bb --config ../clogem-press/bb.edn dev      # build, serve on localhost:1888, rebuild on change
bb --config ../clogem-press/bb.edn build    # write the site to dist/
bb --config ../clogem-press/bb.edn doctor   # report content problems without building
  • README（英文）：每个命令和选项、一屏看完的约定，以及主题的设置。
  • 演示网站（英文）：一个可以照着复制的完整网站，每次改动时测试都会构建它。
  • config.example.edn：每项设置及其默认值。
  • DESIGN.md（英文）：设计及其背后的理由。

隐私

本页

本页不设置 Cookie，不运行任何脚本，也不从其他网站加载任何内容：它的样式和图标都在这一个文件里，字体也来自本站。为本页提供服务的 GitHub Pages 会为它收到的请求保留自己的日志，详见 GitHub 隐私声明（英文）。指向 GitHub 的链接会带你前往 GitHub，适用 GitHub 自己的条款。

生成器

clogem-press 在你自己的电脑上运行。它没有账户，没有遥测，也不检查更新，不会把关于你或你的内容的任何信息发送到任何地方。

它只在下载所需的工具时联网，默认从该工具自己在 GitHub 上的发布页面下载：

  • Chroma，用于代码高亮：在首次构建含有代码的网站时下载，除非关闭了高亮；
  • Pagefind，用于搜索：在首次构建开启了搜索的网站时下载；
  • fswatcher pod，用于监视你的文件：在你第一次运行 bb dev 时下载；
  • 或者在你运行 bb fetch-tool 时下载其中任何一个。

每次下载都会用 clogem-press 中固定的 SHA-256 哈希值校验，并保存在你的网站以外的缓存中（默认为 ~/.cache/clogem-press/tools），因此只下载一次。网站的配置也可以改用自己为某个工具指定的下载来源和哈希值。已经安装、并在网站配置或 CLOGEM_CHROMA、CLOGEM_PAGEFIND 或 CLOGEM_FSWATCHER 中指定的工具，永远不会被下载。

你构建的网站

用 clogem-press 构建的网站是一个文件夹，由你决定发布到哪里。默认情况下，它不会向其他网站发出任何请求。只有当网站所有者开启 giscus 评论或统计分析（Google Analytics 4、Plausible 或 Umami），或者把徽标或图片写成其他网站上的地址时，它才会这样做。搜索引擎站长平台的验证标签如果由所有者添加，只是页面里的几行内容，不会加载任何东西。网站本身最多会在读者的浏览器中保存四样东西（读者选择的配色模式、选择的语言、读者关闭了哪些“也有其他语言版本”的语言提示条，以及在提供此选项的网站上，读者是否选择搜索所有语言），并且不会把它们发送到任何地方；giscus 评论和统计分析如果由网站所有者开启，会按照各自的条款保存它们自己的数据。
