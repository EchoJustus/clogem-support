clogem-press 是什麼

clogem-press 從一個存放 Markdown 檔案的資料夾建置靜態網站：知識庫、部落格、文件，或三者合一的網站。它沿用 vuepress-theme-vdoing 的內容慣例：加上編號的資料夾會成為側邊欄，front matter 會自動替你寫好，每篇文章都有一個簡短的永久網址。

它在 babashka（英文） 上執行，不需要安裝任何函式庫：Markdown、範本、YAML、HTTP 與訂閱源都已內建於 babashka。

一個網站最多可以容納五種語言：英語、簡體中文、繁體中文、馬來語和泰米爾語。同一篇文章的各語言版本共用一個網址，讀者可以在它們之間切換。

內容與結構

由加上編號的資料夾產生側邊欄，自動寫好 front matter 並提供穩定的永久連結，分類、標籤與彙整頁面，可分頁並支援置頂文章的部落格首頁，麵包屑導覽，上一篇與下一篇連結，目錄頁，以及 Markdown 容器。

多語言與內容探索

五種語言，每篇文章一個網址；canonical 與 hreflang 連結，每種語言一個 Atom 訂閱源，網站地圖，每種語言各有索引的 Pagefind 搜尋，以及可選用的 giscus 留言，每篇文章一個討論串。

開始使用

你需要 babashka（英文） 1.13.219 或更新版本，以及 git。clogem-press 在你的網站資料夾中執行，搭配放在它旁邊的一份產生器副本：

git clone https://github.com/EchoJustus/clogem-press
cd my-site
bb --config ../clogem-press/bb.edn dev      # build, serve on localhost:1888, rebuild on change
bb --config ../clogem-press/bb.edn build    # write the site to dist/
bb --config ../clogem-press/bb.edn doctor   # report content problems without building
  • README（英文）：每個指令與選項、一頁看完的慣例，以及佈景主題的設定。
  • 示範網站（英文）：一個可以照著複製的完整網站，每次變更時測試都會建置它。
  • config.example.edn：每項設定及其預設值。
  • DESIGN.md（英文）：設計及其背後的理由。

隱私權

本頁

本頁不設定 Cookie、不執行任何指令碼，也不從其他網站載入任何內容：它的樣式與圖示都在這一個檔案裡，字型也來自本站。提供本頁的 GitHub Pages 會為它收到的請求保留自己的紀錄，詳見 GitHub 隱私權聲明（英文）。前往 GitHub 的連結會帶你到 GitHub，適用 GitHub 自己的條款。

產生器

clogem-press 在你自己的電腦上執行。它沒有帳號、沒有遙測，也不檢查更新，不會把關於你或你的內容的任何資訊傳送到任何地方。

它只在下載所需的工具時連上網路，預設從該工具自己在 GitHub 上的發行版本下載：

  • Chroma，用於程式碼語法標示：在首次建置含有程式碼的網站時下載，除非關閉了語法標示；
  • Pagefind，用於搜尋：在首次建置開啟搜尋功能的網站時下載；
  • fswatcher pod，用於監看你的檔案：在你第一次執行 bb dev 時下載；
  • 或在你執行 bb fetch-tool 時下載其中任何一個。

每次下載都會以 clogem-press 中固定的 SHA-256 雜湊值驗證，並存放在你的網站以外的快取中（預設為 ~/.cache/clogem-press/tools），因此只會下載一次。網站的設定也可以改用自己為某個工具指定的下載來源與雜湊值。已經安裝、並在網站設定或 CLOGEM_CHROMA、CLOGEM_PAGEFIND 或 CLOGEM_FSWATCHER 中指定的工具，永遠不會被下載。

你建置的網站

用 clogem-press 建置的網站是一個由檔案組成的資料夾，由你決定發布到哪裡。在預設設定下，它不會向其他網站發出任何請求。只有當網站擁有者開啟 giscus 留言或流量分析（Google Analytics 4、Plausible 或 Umami），或把標誌或圖片寫成其他網站上的網址時，它才會這麼做。搜尋引擎網站驗證標籤如果由擁有者加入，只是頁面裡的幾行內容，不會載入任何東西。網站本身最多會在讀者的瀏覽器中儲存四樣東西（讀者選擇的色彩模式、選擇的語言、讀者關閉了哪些「也有其他語言版本」的語言提示列，以及在提供此選項的網站上，讀者是否選擇搜尋所有語言），並且不會把它們傳送到任何地方；giscus 留言和流量分析如果由網站擁有者開啟，會依照各自的條款儲存它們自己的資料。
