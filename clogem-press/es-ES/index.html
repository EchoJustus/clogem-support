Qué es clogem-press

clogem-press crea un sitio web estático a partir de una carpeta de archivos Markdown: una base de conocimiento, un blog, documentación, o las tres cosas en un mismo sitio. Sigue las convenciones de contenido de vuepress-theme-vdoing: las carpetas numeradas forman la barra lateral, el front matter se escribe automáticamente y cada artículo recibe una dirección permanente corta.

Funciona con babashka (en inglés), sin ninguna biblioteca que instalar: Markdown, plantillas, YAML, HTTP y los feeds vienen incluidos en babashka.

Un sitio puede tener hasta cinco idiomas: inglés, chino simplificado y chino tradicional, malayo y tamil. Las versiones de un artículo comparten una misma dirección, así que el lector puede pasar de una a otra.

Idiomas y descubrimiento

Cinco idiomas con una dirección por artículo, enlaces canonical y hreflang, un feed Atom por idioma, un mapa del sitio, búsqueda con Pagefind con un índice por idioma y comentarios opcionales con giscus, con un hilo por artículo.

El tema

Modos de color claro, oscuro y de lectura, resaltado de código, estilos de página de tarjetas y de líneas, una barra de navegación con menú lateral en el móvil, enlaces de edición y fechas de última actualización, una página 404, la tarjeta de perfil y el banner de portada del blog, espacios para HTML personalizado, etiquetas opcionales de analítica y de verificación para consolas de búsqueda, búsqueda opcional entre idiomas y un bb dev más ágil: una sola recompilación por cada tanda de guardados, los errores de compilación mostrados en el navegador, el tema recargado al cambiar y la ruta base del sitio servida tal como se publicará.

Primeros pasos

Necesitas babashka (en inglés) 1.13.219 o posterior, y git. clogem-press se ejecuta desde la carpeta de tu sitio, con una copia del generador al lado:

git clone https://github.com/EchoJustus/clogem-press
cd my-site
bb --config ../clogem-press/bb.edn dev      # build, serve on localhost:1888, rebuild on change
bb --config ../clogem-press/bb.edn build    # write the site to dist/
bb --config ../clogem-press/bb.edn doctor   # report content problems without building

  • El sitio de demostración (en inglés): un sitio completo del que copiar, que las pruebas generan con cada cambio.

Privacidad

Esta página

Esta página no instala cookies, no ejecuta ningún script y no carga nada de otros sitios: sus estilos y su icono están dentro de este único archivo. GitHub Pages, que la sirve, guarda sus propios registros de las peticiones que recibe, como se describe en la declaración de privacidad de GitHub (en inglés). Los enlaces a GitHub te llevan a GitHub, con sus propias condiciones.

El generador

clogem-press se ejecuta en tu propio ordenador. No tiene cuenta, ni telemetría, ni comprobación de actualizaciones, y no envía nada sobre ti ni sobre tu contenido a ninguna parte.

Solo se conecta a internet para descargar una herramienta que necesita, de forma predeterminada desde las versiones publicadas de esa herramienta en GitHub:

  • Chroma, para el resaltado de código, la primera vez que se genera un sitio que contiene código, salvo que el resaltado esté desactivado;
  • Pagefind, para la búsqueda, la primera vez que se genera un sitio que activa la búsqueda;
  • el pod fswatcher, que vigila tus archivos, la primera vez que ejecutas bb dev;
  • o cualquiera de ellos cuando ejecutas bb fetch-tool.

Cada descarga se comprueba con un hash SHA-256 fijado en clogem-press y se guarda en una caché fuera de tu sitio (de forma predeterminada, ~/.cache/clogem-press/tools), así que solo ocurre una vez. La configuración de un sitio puede, en cambio, indicar otro origen y otro hash para una herramienta. Una copia ya instalada, indicada en la configuración del sitio o en CLOGEM_CHROMA, CLOGEM_PAGEFIND o CLOGEM_FSWATCHER, nunca se descarga.

Los sitios que generas

Un sitio generado con clogem-press es una carpeta de archivos que publicas donde quieras. De forma predeterminada no hace ninguna petición a otro sitio. Solo la hace cuando su propietario activa los comentarios de giscus o la analítica (Google Analytics 4, Plausible o Umami), o indica un logotipo o una imagen como una dirección de otro sitio. Las etiquetas de verificación de consolas de búsqueda, si el propietario las añade, son líneas de la página que no cargan nada. Por sí mismo, un sitio guarda hasta cuatro cosas en el navegador del lector (el modo de color elegido, el idioma elegido, qué avisos de idioma «también disponible en…» ha cerrado el lector y, en un sitio que lo ofrezca, si ha elegido buscar en todos los idiomas) y no envía nada de ello a ninguna parte; los comentarios de giscus y la analítica, cuando su propietario los activa, guardan sus propios datos según sus propias condiciones.
